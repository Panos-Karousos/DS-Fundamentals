
# Week 1 - Data Science in Everyday Life

For my Week 1 engagement activity, I looked at how my phone's keyboard uses data science through autocorrect and predictive text.The keyboard uses patterns in language to suggest words and correct spelling mistakes. This is an example of how collecting and analysing data can improve an everyday service.
The main thing I learned was that data science is not just statistics and programming. It is about understanding a problem and using data to make useful decisions.
This example came from my Week 1 engagement activity.
